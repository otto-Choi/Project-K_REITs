# Data

## 정제 데이터 (루트)

노트북에서 직접 사용하는 최종 입력 파일.

| 파일 | 내용 |
|---|---|
| `beta_combined.csv` | 리츠별 반기 조정 베타 병합본 (한국공인회계사회, 2011–2025) |
| `div.csv` | 리츠별 배당 데이터 (특별배당 분리 후 정제) |
| `price_beta_data.csv` | 주가 + 베타 병합 |
| `리츠 목록.csv` | 분석 대상 리츠 목록 |
| `reits_enriched_from_price.csv` | P/FFO 회귀 노트북 산출 — TTM FFO·g 계산 결과 |
| `reits_regression_summary.csv` | P/FFO–g 횡단면 회귀 반기별 요약 (α, β, R²) |

## 원천 데이터 (`raw/`)

| 폴더/파일 | 출처 |
|---|---|
| `베타 데이터/` | 한국공인회계사회 — 반기별 베타계수 CSV (2011–2025) |
| `주가 데이터/` | KRX marcap 라이브러리 — 연도별 시가총액·주가 CSV (gitignored, ~1.5 GB) |
| `리츠 목록/` | 팀원별 리츠 목록 취합 및 병합 중간본 |
| `중간 가공/` | 수집·탐색 단계 노트북 및 중간 산출물 (gitignored) |
| `리츠 22-24 csv 형식 합본.csv` | 리츠 18종목 일별 주가 2022–2024 (GARCH 노트북 입력) |
| `포트폴리오 22-24 csv 형식 합본.csv` | 개인 포트폴리오 구성 종목 일별 주가 2022–2024 (GARCH 노트북 입력) |
| `reit_panel_simple.csv` | 리츠별 반기 P/FFO 패널 데이터 (P/FFO 회귀 노트북 입력) |
| `*.csv` | 병합·정제 과정 중간 파일 |
